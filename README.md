# 🎨 VS Code Custom Theme 



A sleek, modern, and eye-pleasing VS Code theme designed for developers who love clean syntax highlighting and a focused coding environment.

---

## ✨ Features
* **Custom Syntax Highlighting:** Optimized for JavaScript, Python, HTML/CSS, and more.
* **Easy on the Eyes:** Carefully picked colors to reduce eye strain during long coding sessions.
* **Readable UI:** Distinguishable sidebar and editor tabs.

## 🚀 Installation

1. Copy the JSON code from the `theme.json` file.
2. Open **VS Code**.
3. Go to `Settings` > `Workbench: Color Customizations`.
4. Click on `Edit in settings.json`.
5. Paste the code inside the curly braces.
